# 批量套边框 · UX 交互说明书

## 1. 功能定位与设计背景

批量套边框是面向广告投放与社媒短视频的批量视觉包装工具。

- **核心业务痛点**：生图模型无法直接生成带透明镂空的素材；即使同一提示词生成的不同边框，其“洞口”尺寸与位置也有差异（洞宽通常在 61%~87% 之间波动，且很难恰好为 9:16），逐张手动裁剪对齐成本极高。
- **设计解法**：
  - **三步向导**：生成边框（出图后自动抠除中心纯色区） ➔ 统一调整视频矩形（所见即所得） ➔ 边框与视频配比批量合成。
  - **容差机制**：默认采用「视频在图下 + 矩形略大于洞口」，由边框自身边缘充当天然遮罩裁切视频，对齐精度要求直接归零。
  - **全流程任务化**：第 1 步点击生成即在任务中心建档留存，中途离开不丢进度，随时可恢复操作。

```
[步骤一：生成边框]              [步骤二：调整视频位置]               [步骤三：套用与合成]
提示词 + 参考图                 视频池上传 / 选自资源库             边框池 × 视频池
   ↓                               ↓                                   ↓
生成 9:16 原图                  共用一套 9:16 视频矩形              全排列 / 逐条轮换 (≤20条)
   ↓                               ↓                                   ↓
自动挖空中心纯色 (支持重试)       拖动/缩放/透视边框/勾选边框         逐条模拟合成 ➔ 播放 ➔ 批量下载
```

## 2. 页面框架与全局交互

### 2.1 容器与顶栏

```
┌────────────────────────────────────────────────────────────────────────┐
│  ← 批量套边框                     ①生成边框 ── ②调整视频位置 ── ③套用与合成  ✕ │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│                      主工作区（按当前步骤动态渲染）                        │
│                                                                        │
├────────────────────────────────────────────────────────────────────────┤
│  [上一步]                                                      [下一步] │
└────────────────────────────────────────────────────────────────────────┘
```

1. **顶栏**：
   - **返回按钮（←）与关闭按钮（✕）**：点击退出工作台。若当前已有进度（已输入提示词、有边框或有视频），自动静默将最新状态写回任务草稿。支持键盘 `Escape` 键快捷退出。
   - **步骤指示器（Step Indicator）**：依次展示 `① 生成边框`、`② 调整视频位置`、`③ 套用与合成`，高亮当前所在步骤。
2. **底栏步骤流转条**：
   - **步骤 0（生成边框）**：仅展示「下一步」，置灰条件：未挖空出至少 1 张边框。
   - **步骤 1（调整视频位置）**：展示「上一步」与「下一步」，下一步置灰条件：未勾选任何边框或视频池为空。
   - **步骤 2（套用与合成）**：展示「上一步」；若未开始合成展示「开始套框合成 (N)」，若已合成展示成片操作底栏。

## 3. 步骤一 · 生成边框（Generate Frames）

### 3.1 页面布局

采用左右分栏：
- **左侧**：上方为「生成结果」缩略图网格，下方为「提示词与参数控制条」（Composer）。
- **右侧**：大预览区（Hero Preview），默认放大展示当前选中的边框。

```
┌──────────────────────────────────┬─────────────────────────────────────┐
│ 🖼 生成结果 (4/24 · 挖空 3 · 失败 1) │ 边框 1 · 已挖空                [<] [>]│
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐      │                                     │
│ │#1  │ │#2  │ │#3  │ │#4  │      │                                     │
│ │已挖空│ │已挖空│ │已挖空│ │重试│      │           边框大图展示区            │
│ └────┘ └────┘ └────┘ └────┘      │         (透明区域棋盘格显示)         │
│                                  │                                     │
├──────────────────────────────────┤                                     │
│ [参考图 1 ✕]                      │                                     │
│ 描述边框风格，中间留出纯色空白区… │                                     │
│ [+]参考图   [9:16]  [-] 4 [+]  [↑]│                                     │
└──────────────────────────────────┴─────────────────────────────────────┘
```

### 3.2 交互行为与状态

#### 1. 提示词与参考图输入（左下）
- **多行文本域**：
  - 支持随内容自动增高（最大 160px），快捷键 `Enter` 快速触发生成（`Shift + Enter` 换行）。
  - Placeholder 引导文案：`描述边框风格，并写清「中间留出大块纯色空白区」…`。
- **参考图停靠区（Idea Dock）**：
  - 上传或从资源库添加的图片以胶囊标签展示在输入框上方，悬停可点 `✕` 移除。
  - 参考图不限张数。
- **添加参考图菜单（`+` 按钮）**：
  - 点击弹出气泡菜单：
    - **本地上传**：唤起系统文件选择框（`image/*`），支持多选。
    - **从资源库选择**：唤起资源库弹窗（内置「角色」与「图片」双 Tab），支持多选勾选入库。
- **右侧控件**：
  - **比例标签**：固定标注 `9:16`（边框严格适配竖屏短视频）。
  - **张数步进器**：单次生成张数调节（1~8 张，默认 4 张）。
  - **生成按钮（`↑`）**：
    - 校验拦截：提示词为空且无参考图时 Toast 提示 `先写边框描述，或挂一张参考图`。
    - 总数截断：边框上限为 24 张（`FRAME_CAP = 24`），若超出则拦截并提示；若剩余名额不足自动截断并 Toast 提醒。
    - 点击后：立即建档任务中心草稿，按钮转为 Loading 动画。

#### 2. 生成与抠像时序（左上网格）
- **状态流转**：
  - `出图中…`（生成卡片占位，带有脉冲加载动画）
  - ➔ `原图`（垫白底显示，中心尚未镂空）
  - ➔ `抠像中…`（带有 Spinner 旋转动画）
  - ➔ `已挖空`（剪刀图标 ✂️，中心呈现透明棋盘格）或 `抠像失败`（警告红标）。
- **卡片操作**：
  - **点击卡片**：高亮并同步更新右侧大预览。
  - **删除（✕）**：悬停时显示右上角删除图标，点击将该边框移出列表。
  - **失败重试（RotateCcw）**：抠像失败卡片底部展示重试按钮，附带原因提示（如 `未找到足够大的中间纯色区域，已自动跳过`），点击重试可重新触发抠像并成功挖空。

#### 3. 大预览区（右侧）
- **空态**：展示占位图标与操作指引（提示固定 9:16、出图后自动抠像）。
- **聚焦预览态**：
  - 左右翻页按钮（`<` 与 `>`）：支持快速切换上一张/下一张。
  - 状态指示标签：顶栏显示 `边框 No · [已挖空 / 抠像中 / 出图中 / 抠像失败 / 原图]`。
  - 抠像失败态：大图下方居中提供「抠像失败 · 重试」按钮。

## 4. 步骤二 · 调整视频位置（Adjust Placement）

### 4.1 页面布局

- **左侧**：上方「视频池面板」，下方「视频位置控制面板」。
- **右侧**：中央对齐交互舞台（PlaceStage）+ 底部边框缩略图轮播勾选条。

```
┌──────────────────────────────────┬─────────────────────────────────────┐
│ 🎬 视频池 (2条)             [+]清空│ 调整视频位置 (第 1/4 张 · 已勾选 4)  [透视] [全选] │
│ [封面] 视频A.mp4              [✕]│                                     │
│ [封面] 视频B.mp4              [✕]│                 [<]                 │
│ [+] 添加视频                     │           ┌─────────────┐           │
├──────────────────────────────────┤           │   边框图     │           │
│ 视频位置 (整个任务共用一套)        │           │ ┌─────────┐ │           │
│ 层级:  [视频在图下] [视频在图上]    │           │ │ 视频画面 │ │     [>]   │
│ 大小:  [====●========] 74%       │           │ └─────────┘ │           │
│ 圆角:  [●============] 0         │           └─────────────┘           │
│ 坐标:  X 13% · Y 13%     [⌖复位居中]│                                     │
│                                  │ ┌────┐ ┌────┐ ┌────┐ ┌────┐         │
│                                  │ │☑#1 │ │☑#2 │ │☑#3 │ │☐#4 │ (轮播勾选)│
└──────────────────────────────────┴─┴────┴─┴────┴─┴────┴─┴────┴─────────┘
```

### 4.2 交互行为与状态

#### 1. 视频池交互（左上）
- **空态**：支持拖拽视频放入，或点击「上传视频」（本地 MP4/MOV）与「从资源库选择」。
- **列表态**：展示视频首帧封面、文件名、删除（✕）按钮，末尾提供 `+` 添加格。
- **实时联动**：视频池第一条视频自动实时注入到右侧舞台及底部缩略图的 9:16 矩形中播放，所见即所得。

#### 2. 位置控制面板（左下）
- **层级单选（Z-index）**：
  - **视频在图下**（默认）：边框覆盖在视频上方。超出镂空洞口的内容自动被边框裁掉，圆角由洞口天然决定，**圆角滑杆自动禁用**。
  - **视频在图上**：视频盖在边框上方。用户可自行调节圆角，但超出镂空的部分会露在边框外面。
- **大小滑杆（Size）**：范围 25% ~ 140%（默认 74%），滑杆拖动时**围绕矩形中心等比缩放**，不会向右下方偏移。
- **圆角滑杆（Radius）**：范围 0 ~ 24，仅在「视频在图上」时激活。
- **复位居中按钮（⌖）**：点击将 X, Y, Size 重置为默认基准（13%, 13%, 74%），保留当前层级与圆角。

#### 3. 舞台拖拽交互（右侧中央）
- **拖动移动**：指针按住矩形区域自由拖动，边缘自动施加安全限制（至少保留 10% 面积在画布内，防止拖飞丢失）。
- **四角缩放**：矩形四角提供抓手（`nw`, `ne`, `sw`, `se`），拖动时对角点锚定，严格锁 9:16 比例缩放。
- **键盘微调**：矩形选中时，支持键盘方向键（`←` `→` `↑` `↓`）精细位移（每次 0.5%，按住 `Shift` 每次 2%）。
- **透视机制（Ghost Mode）**：
  - **拖动自动透视**：拖动或缩放瞬间，边框自动降低透明度（40% 半透明），使用户能够清楚透视看到被边框遮挡的多余视频边缘。
  - **手动透视开关**：右上角提供「透视边框」（Eye 图标）按钮，点击可常驻开启/关闭半透明透视。

#### 4. 底部边框缩略图条（Strip）
- 横向排列展示所有挖空边框的实时叠放预览。
- **单张点击**：切换右侧主舞台当前对齐参照图。
- **单张勾选框（Checkbox）**：勾选表示“采用该边框合成”，取消勾选表示“淘汰该边框”。当某张边框因 AI 生成缺陷导致洞口严重偏斜时，用户可在此直接剔除。
- **全选/全不选**：右上角提供一键切换全部边框勾选状态。

## 5. 步骤三 · 套用与合成（Apply & Compose）

### 5.1 页面布局

- **左侧**：已选边框池预览、视频池管理、配比模式切换、成片总数预估、开始合成按钮。
- **右侧**：成片卡片网格列表、底部批量操作栏。

```
┌──────────────────────────────────┬─────────────────────────────────────┐
│ 🖼 已选边框 (3个 · 视频在图下 74%) │ 套框成片 (3/6 已合成)                  │
│ [框1] [框2] [框3]                │ ┌─────────┐ ┌─────────┐ ┌─────────┐ │
│                                  │ │☑ 1      │ │☑ 2      │ │☑ 3      │ │
│ 🎬 视频池 (2条)             [+]清空│ │[合成中…]│ │[▶ 播放] │ │[排队中…]│ │
│ [封面] 视频A.mp4              [✕]│ │边框1+视A│ │边框1+视B│ │边框2+视A│ │
│ [封面] 视频B.mp4              [✕]│ └─────────┘ └─────────┘ └─────────┘ │
├──────────────────────────────────┤                                     │
│ 6 条成片 (3 边框 × 2 视频) [全排列▾]│                                     │
│ [       开始套框合成 6 条       ]│                                     │
├──────────────────────────────────┴─────────────────────────────────────┤
│ 3 框 · 9:16 · 全排列                       [全选/取消全选] [⬇ 批量下载 (2)] │
└────────────────────────────────────────────────────────────────────────┘
```

### 5.2 交互行为与状态

#### 1. 配比规则与合成上限（左侧）
- **配比模式（Picker 下拉）**：
  1. **全排列（Cross，默认）**：每个边框与每条视频两两配对，成片数 = `边框数 × 视频数`。
  2. **逐条轮换（Cycle）**：边框与视频按索引循环对应配对，成片数 = `max(边框数, 视频数)`。
- **上限熔断防呆（Cap Safeguard）**：
  - 单次合成上限为 **20 条**（`COMPOSE_CAP = 20`）。
  - 若组合数超过 20 条，数字高亮红色报警，显示 `⚠ 超出上限 20`，同时「开始套框合成」按钮禁用，Tooltip 引导用户切换为“逐条轮换”或减少素材。
- **开始合成**：
  - 点击「开始套框合成 N 条」，按钮转为 `合成中…`，右侧网格生成 N 个卡片骨架并进入队列流水线。

#### 2. 成片网格卡片（右侧）
- **合成流水线时序**：
  - 单条卡片依次经历 `排队中`（微暗文字）➔ `合成中`（Spinner + 文字，单条耗时 ~820ms）➔ `完成`。
- **成片卡片元素**：
  - 左上角勾选框（用于批量下载）。
  - 右上角成片编号（#1, #2...）。
  - 底部标签：标注该条所用 `边框编号` 与 `原视频文件名`。
  - **播放预览（PlayModal）**：合成完成后，卡片中央浮出播放按钮（▶），点击弹出视频播放器模态浮层，可全屏/暂停/拖动进度条，按 `Escape` 或点击空白处关闭。

#### 3. 底部批量下载栏（Footer）
- **元信息**：显示当前批次参数（如 `3 框 · 9:16 · 全排列`）。
- **全选/取消全选**：一键切换所有已合成成片的勾选态。
- **批量下载**：展示已勾选且已合成的数量 `批量下载 (M)`，点击后依次触发浏览器文件下载，文件以 `套框-序号-边框编号.mp4` 规范命名。

## 6. 任务中心集成与草稿恢复机制

### 6.1 自动建档与双向同步
1. **触发建档**：在第 1 步点击「生成边框」的瞬间，系统即向平台任务中心提交一条新任务，默认命名规则为 `套框-MMDD`（如 `套框-0917`）。
2. **草稿持久化**：用户后续在工具内的所有改动（增删边框、抠像重试、修改视频矩形、切换配比模式、执行合成），均实时自动保存到该任务的 `frameDraft` 字段中。

### 6.2 中途离开与再次进入
- **从任务中心点击任务卡片**：
  - 直接打开全屏工作台，精准恢复至上次离开时的步骤状态、边框列表、视频池素材及对齐矩形。
- **从工具箱再次打开「批量套边框」**：
  - 若本地检测到有未完成的草稿，弹出模态拦截对话框：
    - **对话框文案**：`检测到未完成的操作：您上次进行到了「步骤名」步骤，已挖空 X 个边框，视频池里有 Y 条，是否继续？`
    - **操作按钮**：
      - 「继续操作」（主按钮）：完全恢复草稿现场。
      - 「重新开始」（描边按钮）：清空草稿状态，开启全新空白向导。

## 7. 交互状态与边界异常汇总

| 场景 | 触发条件 | 交互与视觉反馈 |
| :--- | :--- | :--- |
| **生图拦截** | 提示词为空且未添加参考图时点生成 | 弹出 Toast 提示：`先写边框描述，或挂一张参考图`。 |
| **生图满额** | 边框列表已有 24 张时点生成 | 生成按钮禁用，Toast 提示：`边框最多 24 张，删掉几张再生成`。 |
| **名额不足截断** | 现有 22 张，单次选择生成 4 张 | 实际仅生成 2 张，Toast 提示：`边框上限 24 张，本次只生成 2 张`。 |
| **抠像失败** | 生成过程中无法检测到纯色镂空区域 | 缩略图打上红标与「重试」按钮，大预览区出现重试横幅，重试固定成功。 |
| **步骤一闸门** | 列表中没有成功挖空的边框 | 底栏「下一步」按钮置灰禁用，Tooltip 提示 `先抠像出至少一个边框`。 |
| **步骤二闸门** | 未勾选任何边框或视频池为空 | 底栏「下一步」按钮置灰禁用，Tooltip 明确指出阻断项（边框或视频缺失）。 |
| **矩形防飞出** | 舞台拖动将矩形拖向屏幕外 | 限制拖拽边界，强制至少 10% 面积留在舞台内，防止拖飞丢失。 |
| **层级联动** | 选择「视频在图下」 | 圆角滑杆变灰禁用，显示提示文案 `圆角由洞口决定，这里不用调`。 |
| **合成超额阻断** | 组合条数 > 20 条 | 条数标红报警，合成按钮置灰，Tooltip 提示改用逐条轮换或减少素材。 |
| **批量下载拦截** | 未勾选已合成成功的成片 | 下载按钮置灰禁用，Tooltip 提示 `请先勾选已合成的成片`。 |

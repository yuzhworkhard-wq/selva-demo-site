# 工具箱 · 视频生成：完整交互链路

> 给研发的产品/UX 说明。描述当前已落地的交互，作为实现对齐基准。  
> 实现入口：平台 `site/` 工具箱卡片 → iframe `clone/index.html?embed=1` → `VideoGenModal` / `VideoGenTaskDetail`。  
> 裂变维度细则见 `source/docs/prompt-fanout-dimensions.md`。

---

## 1. 产品定位

视频生成把**一句话创意**一次变成 **N 条可投放成片**。用户写完就提交，中间没有「预览脚本再确认」这一步。Magic Prompt 开启或自动时，脚本在提交瞬间配好，事后可在任务详情里逐条对照；关闭时直接使用用户原文。

核心规则：**用户写死的内容，N 条逐字沿用；没写的部分，由 Magic Prompt 决定要不要拉开差异。**

这是一条固定流水线：输入 → 判一次意图并写 N 条 prompt → 出 N 条片。

## 2. 入口与承载

### 2.1 用户怎么进来

1. 打开某个项目下的文件夹工作台
2. 左侧切到「工具箱」
3. 在「视频生成工具」里点 **视频生成**

平台不进工具详情页，直接铺一层全屏 iframe（`clone/index.html?embed=1`），并给子应用发 `selva-vgen-open`。

同一 iframe 还承载视频克隆、视频裂变。页面空闲时会预载，点开应立刻看见界面。

### 2.2 壳层行为

- 顶栏左侧返回、右侧关闭：有未提交内容时只隐藏、不销毁会话。
- 点平台侧栏任意导航：同样隐藏 iframe，进度留在子应用里。
- 再次打开：若上次留下了文字或参考素材，弹出「检测到未完成的操作」——**继续操作**回到原输入，**重新开始**清空重来。
- 子应用弹窗（资源库、继续操作、失败原因等）打开时，平台侧栏叠一层半透明遮罩，观感是全视口居中弹窗。

独立跑 `apps/video-clone`（非 embed）时，左侧还有一套工具箱子导航；嵌入平台时这套侧栏不出现。

## 3. 主路径总览

```
工作台 · 工具箱
    → 视频生成（单页输入卡）
        → 点发送 / Enter
            → 顶部 toast「N 条视频已提交至任务中心」
            → 输入框与参考素材清空，模型/画幅/时长/条数/Magic 保留
            → 任务中心立刻多一行（状态：生成中）
            → 约 5 秒后状态变为已完成 / 部分完成 / 失败
    → 任务中心点该行
        → 同一 iframe 切到任务详情
            → 左：N 条成片切换 + 预览 + 下载 / 重新编辑 / 裂变
            → 右：你的输入 ⇄ 本条提示词
```

提交后**留在输入页**。用户改一版再发，不用重新进工具。

## 4. 输入页

整页只有一步。上半是输入卡，下半是爆款视频库。

标题文案：「一句话，**裂变多条广告视频**」。  
副文案：「用你选的视频模型，把一个创意自动裂变成多条不同脚本的成片」。

### 4.1 输入卡结构（从上到下）

1. **已挂载素材条（dock）** — 有素材才出现
2. **富文本输入框** — contenteditable，支持 `@` 引用
3. **字数** — `当前/上限`，超限标红
4. **拦截条** — 模型能力冲突时出现
5. **底栏** — 左：加素材、Magic Prompt；右：模型、画幅、时长、条数、发送

发送条件：输入框有字 **或** 已挂至少 1 个素材；同时没有任何拦截项；同时不在提交过渡中。

## 5. 参考素材

### 5.1 两类来源，一个配额

底栏 `+` 打开菜单，只有两个入口：

| 入口 | 行为 |
|---|---|
| 本地上传 | 一个文件框同时收图 / 视频 / 音频，按 `file.type` 自动归类 |
| 从资源库选择 | 角色 / 图片 / 视频 三个 tab，先勾选再确定 |

用户不用先声明「这是参考图还是参考视频」。角色和图片都占**参考图**名额，视频占**参考视频**名额。音频只能本地上传。

菜单底部一行实时配额，例如 `参考图 1/4 · 参考视频 0/3 · 参考音频 0/1`。满了的入口置灰。当前模型完全不收的类型，菜单里不出现。

### 5.2 资源库弹窗

- 标题：「从资源库选择 · 我的资源库」
- Tab 上带该类数量
- 卡片：封面 + 名称 + 元信息；视频卡有播放角标
- 勾选打勾；该类名额用尽后未选中的卡片点不动
- 底栏左侧是本次占用配额，右侧「取消 / 确定 (N)」
- Escape 或点遮罩关闭；取消＝这次勾的都不算
- 确定后顶部 toast：「已从资源库添加 N 个素材」

### 5.3 dock 上的素材 chip

- **图**：缩略图 + 右上角 ×
- **视频 / 音频**：图标 + 文件名 + ×
- 超出当前模型上限的那几张描红，tooltip：「超出 {模型} 的{类型}上限，请删除」
- 删一张：dock 少一张；输入框里对应的 `@图片N` chip 一并消失，后面的编号前移

本地上传放不进去（模型不收 / 该类已满）时，文件不静默丢掉，顶部警告 toast 报「N 个文件没能添加：原因」。

### 5.4 换模型不替用户删素材

已挂素材全部保留。新模型装不下时，发送按钮锁住，拦截条写清要删几个。删哪张由用户自己决定。

时长档位：新模型认旧档就保留，否则落到该模型第一档。

## 6. 输入框与 `@` chip

输入框是 contenteditable，**不是** textarea。引用素材必须看得见那张图，纯文字「参考图 1」没有指认力。

对外仍只产出纯文本：chip 的可见文字就是 `@图片1`，下游字数统计、brief 解析、任务详情「你的输入」都吃这一串。

### 6.1 什么时候弹出 `@` 菜单

光标前出现**词首**的 `@` 就弹。后面可以继续打过滤词。

不算引用、不弹菜单：

- `@` 紧跟在字母或数字后面（邮箱、`@2x`）
- `@` 后面已经打了空格
- 过滤词超过 12 个字

菜单位于光标下方；下方放不下就翻到上方。点菜单不会让输入框失焦。

### 6.2 菜单里有什么

已挂载素材按 dock 顺序排列：

- 图：缩略图 + `@图片1` + 文件名
- 视频 / 音频：图标 + `@视频1` / `@音频1` + 文件名

过滤：按文件名或 `@图片1` 这类标签匹配。

没命中时：

- 还没挂素材 → 「还没有挂载参考素材」
- 有素材但对不上过滤词 → 「没有匹配「xxx」的素材」

菜单最底下永远有一条 **「添加参考素材…」**，点开就是资源库弹窗。

### 6.3 选中之后

已经打进去的 `@图` 这几个字被删掉，原地插入一枚原子 chip：

- `contenteditable=false`，退格一次整颗删掉
- 图片 chip 带缩略图，视频/音频带图标
- 插入后自动跟一个空格，接着打字不会粘在 chip 上

键盘：

| 按键 | 菜单打开时 | 菜单关闭时 |
|---|---|---|
| ↑ / ↓ | 高亮上/下一项 | — |
| Enter / Tab | 插入当前项 | Enter 等同点发送（有拦截则不发） |
| Shift+Enter | 换行，并收起菜单 | 换行 |
| Escape | 只关菜单 | — |

粘贴只收纯文本，外部样式进不来。

### 6.4 chip 和素材的绑定

chip 按「类型 + url」认领。删掉某张图、或换模型导致该类素材被清掉时：

- 认不到的 chip 就地移除
- 认得到的刷新编号（删了 `@图片1`，原来的 `@图片2` 变成 `@图片1`）

从爆款库灌模板、重新编辑回填、提交后清空：文本里的 `@图片1` 会按当前素材还原成 chip。对不上真实素材的 `@图片9` 保持普通文字。

Placeholder：「描述你想生成的视频，输入 @ 引用参考素材…」

## 7. 底栏参数

### 7.1 视频模型

两栏选择器：左模型族，右具体版本。

| 族 | 版本 | 时长 | 参考图 | 参考视频 | 参考音频 | 字数 | 额度/条 |
|---|---|---|---|---|---|---|---|
| Seedance | 2.0 | 15s 锁定 | 4 | 3 | 1 | 5000 | 3 |
| Seedance | 2.0 Fast | 15s 锁定 | 4 | 3 | 1 | 5000 | 2 |
| Seedance | 2.0 Mini | 15s 锁定 | 4 | 3 | 1 | 5000 | 1 |
| Minimax H3 | H3 | 15s / 10s | 5 | 不支持 | 1 | 2000 | 1 |
| Google omni | omni | 10s 锁定 | 4 | 1 | 不支持 | 2000 | 1 |

每条版本展示：名称、额度、一句话卖点、能力标签（时长 / 各类素材上限 / 字数）。

窄屏时面板翻到按钮左侧或贴底弹出。点外面或 Escape 关闭。

默认模型：**Seedance 2.0**。

### 7.2 画幅

真下拉：`9:16` / `1:1` / `16:9`。默认 `9:16`。

### 7.3 时长

模型只有一档 → 锁定态，锁图标，点不动，tooltip 说明「时长固定」。  
模型有多档（目前仅 Minimax H3）→ 真下拉。

### 7.4 条数

步进器 1–8，默认 **4**。上箭头加、下箭头减，到头禁用。  
条数只决定出几条；「有多不一样」归 Magic Prompt。

### 7.5 Magic Prompt

底栏一颗药丸。悬停出现「Magic Prompt」标签。点开：

> 扩充你写的提示词，让多条视频的画面更丰富、彼此更不一样。你明确写了的内容不会改动。

三档：

| 档位 | 行为 |
|---|---|
| 自动（默认） | 输入较粗 → 扩写并拉开 N 条差异；锁死项 ≥ 6 条 → 生成一份共享补全脚本 |
| 开 | 生成 1 条时只扩写；生成多条时扩写并让未写死的维度各取不同值 |
| 关 | N 条直接共用用户原始输入，只剩模型自身随机 |

药丸在「开 / 自动」时呈开启态，「关」时呈关闭态。

### 7.6 发送

圆形上箭头。提交过渡约 1.2 秒转圈。有拦截时 tooltip 直接显示第一条原因。

拦截文案示例：

- `{模型} 最多 4 个参考图，请移除 2 个`
- `{模型} 不支持参考视频，请移除已添加的 1 个`
- `{模型} 提示词最多 2000 字，请删掉 128 字`

字数超限照实显示（例如 `2128/2000` 标红），**不替用户砍字**。

## 8. 爆款视频库

输入卡下方。热度 = 近 7 日被采用次数（demo 写死）。点一张卡 = 把它的提示词灌进输入框。封面是成片截图，**不自动挂成参考图**。

### 8.1 首页预览

- 分类 chip：全部 / 口播带货 / 网赚短剧 / 开箱测评 / 产品特写 / 街头采访 / 宠物萌宠 / 美妆个护 / 游戏推广 / UGC 素人 / 电影质感
- 当前分类按热度取前 12 张
- 卡片 9:16；角标：热度、来源、近 3 天打 NEW
- 标题和「用这条」hover 才出
- 「查看全部」进全屏库，并带上当前分类

### 8.2 全屏库

盖住内容区（含顶栏），平台侧栏保留。

- 搜索：标题 / 提示词 / 来源
- 排序：热度 / 最新
- 同一套分类 chip
- 点卡片：灌进输入框并关闭库
- Escape / 返回 / 关闭：回到输入页

## 9. 提交之后

### 9.1 输入页自己

- 顶部 toast：「4 条视频已提交至任务中心」（1 条时：「视频已提交至任务中心」）
- 输入框清空，`@` chip 全部消失
- 参考素材清空
- 模型 / 画幅 / 时长 / 条数 / Magic **保持原值**，方便连发下一批

### 9.2 任务中心列表

立刻多一行：

| 字段 | 值 |
|---|---|
| 任务 ID | `T-YYYYMMDD-C01` 递增 |
| 任务名称 | `视频生成 · N 条`；N=1 时为 `视频生成` |
| 状态 | 先「生成中」，约 5 秒后结算 |
| 来源 | 工具箱 |
| 工具 | 视频生成 |
| 产出物摘要 | 生成中 → `视频生成中`；全成 → `视频生成完成 N 条`；部分失败 → `N 条中 X 条成功、Y 条失败`；全挂 → `N 条全部生成失败` |
| 关联产品 | — |

侧栏任务徽标统计「生成中 + 待确认」数量。

点这一行：**不进平台通用任务详情**，仍在同一 iframe 里打开视频生成详情。

### 9.3 逐条成败（demo 规则，产品要能稳定演示）

- 一批 ≥ 3 条：第 3 条固定失败 → 列表「部分完成」
- 输入里写了「测试失败」：整批失败
- 其余成功

列表摘要和详情里挂掉的必须是同一条。失败条目不计入额度。

历史种子任务在 iframe 就绪时由宿主灌入（`selva-clone-seed`）。点开历史行，看到的详情界面与新提交的任务同一套。

## 10. 任务详情

左右两栏。换一条任务时，选中条回到第 1 条，右侧 tab 回到「你的输入」。

### 10.1 顶栏

任务名称 + 状态胶囊：

- 生成中（转圈）
- 已完成
- 部分完成
- 生成失败

返回：关掉 iframe，回到任务中心列表。

### 10.2 左栏 · 成片

**多条时**上方有选择器：

- 标题「N 条成片」
- 有失败时，同行一枚失败 chip（「2 条失败」/「全部失败」），点开失败原因弹窗
- 「下载全部」：只下成功的，失败的不混进去；生成中或 0 条成功时禁用

缩略图轨：

- 横滑，左右两端有渐隐表示「那边还有」
- 每张：画面（生成中转圈 / 失败三角 / 成片首帧）+「视频 N」+ 对勾或 ✕
- 键盘：左右键换条，Home / End 到头尾；当前条自动滚进可视区
- hover 快捷：失败条 → 重新生成这一条；成功条 → 下载这一条  
  成功条没有「再跑一遍」——要变方向走裂变

主预览：

- 生成中：占位「生成中，成片就绪后在此预览」
- 失败：成片位直接写原因、错误码、查看原因、重新生成这条
- 成功：点画面播放 / 再点暂停；未播放时中央播放钮。角标「视频 2 / 4」

底栏三个按钮：

| 按钮 | 作用对象 | 禁用 |
|---|---|---|
| 下载 | 当前这条成片 | 生成中 / 当前条失败 |
| 重新编辑 | 整批的「你的输入」 | 从不禁用 |
| 裂变（主按钮） | 以当前这条为底，开新任务 | 生成中 / 当前条失败 |

裂变的完整交互见 `docs/video-fanout-ux.md`。

主按钮给裂变：出了一条能看的片之后，下一步是拿它当底继续试。重新编辑是改 brief 重开一批。不说方向的「重新生成」只出现在失败态。

### 10.3 右栏 · 来源

两个并列 tab，复制按钮跟在**当前激活的 tab** 后面。

**你的输入**

- 若这批本身是裂变来的：最上方「裂变来源」块（基准缩略图、只变哪几维、用户原话、是否「基准来自画面分析」、来源任务 ID 可复制）。点缩略图放大看片。
- 参考图钉在文字上方、不随正文滚走；点开新标签看大图
- 正文：用户当初那份 brief（含 `@图片1` 纯文字）
- 没有文字时：「这条任务没有文字输入」

**本条提示词**

- 单条扩写任务的 tab 名是「扩写提示词」
- 多条且脚本各不相同时，tab 名是「视频 N 的提示词」
- 自动档生成共享补全脚本时，tab 名是「本批提示词」
- Magic=关时只显示「你的输入」，省略提示词 tab
- 生成中、甚至失败的那条也看得到脚本——发出去的原文是废片归因的第一手材料
- 图例：
  - 实底高亮 = 你写死的，逐字不动
  - 斜体变量 = 系统补全
  - 若是裂变任务，再多一色 = 本次在变
- 脚本里的参考图以带缩略图的 `@参考图N` chip 出现

**详细信息**（钉在右栏底部，不进滚动区）

平时只摊「模型 · 时长」。悬停「详细信息」看全表：任务 ID（可复制）、工具名称、模型、时长、画幅、参考视频/音频个数、生成数量（含成败拆分）、Magic Prompt、创建时间、耗时（仅已完成）。没值的字段整行不出现。

### 10.4 失败原因弹窗

点失败 chip 或成片位「查看原因」。

- 说明：这批共 N 条，X 条失败，Y 条已正常出片；失败不计入额度
- 逐条：视频序号、原因、建议、错误码
- 主按钮：「重新生成失败视频（X 条）」——失败的几条打成**一条新任务**，成功的不动
- Escape / 点遮罩 / 关闭

### 10.5 重新编辑

回到输入页，把上次的 brief、参考图/视频/音频、条数、模型、画幅、时长、Magic **原样灌回去**。

提交算**新任务**。原任务和那批成片留着可对比。  
同时把平台侧栏切到工具箱高亮（工作流属于工具箱，不应还停在任务中心）。

### 10.6 重新生成（仅失败）

拿该条当时的脚本和素材再提一条新任务。原任务、本页零变化。唯一反馈是顶部 toast：

- 单条：「已用视频 3 的设定提交新任务」
- 批量失败重试：「已提交新任务重新生成 2 条失败视频」

## 11. 会话与快捷键汇总

| 场景 | 行为 |
|---|---|
| 关闭 / 返回 / 点侧栏离开 | 有文字或素材 → 会话保留；空页 → 卸掉 |
| 再次打开且有会话 | 「您上次写的内容还留着，是否继续？」 |
| Escape | 关当前浮层（`@` 菜单、模型选择、Magic、加素材、资源库、爆款库、继续操作弹窗）；不关主流程 |
| 发送后 | 页面不动，只清输入 |

|---|---|
| 工具箱入口 / iframe 开关 | `site/actions/interactions.js` `openVideoGenTool` |
| 输入页 | `apps/video-clone/src/VideoGenModal.jsx` |
| `@` chip / 富文本 | 同文件 `ComposerEditor` / `AtMenu` |
| 模型能力口径 | 同文件 `VIDEO_MODEL_CONFIG`（须与平台 `WORKFLOW_VIDEO_MODEL_CONFIG` 对齐） |
| Magic / N 条脚本 | `apps/video-clone/src/briefParser.js` `buildVariantScripts` |
| 宿主协议 / 任务表 | `apps/video-clone/src/EmbedApp.jsx` |
| 任务详情 | `apps/video-clone/src/VideoGenTaskDetail.jsx` |
| 列表行 upsert | `site/actions/interactions.js` `upsertCloneTask` |
| 历史任务种子 | `site/render/helpers.js` `VGEN_TASK_SEEDS` + `buildVGenTaskSeeds` |

改模型能力、失败规则、列表摘要或详情字段时，列表和详情必须说同一件事。

# 批量混剪 · UX 交互说明

## 1. 功能定位

上传同一品牌/产品的多条视频素材，系统按不同拼接顺序批量合成完整广告。差异来源是**片段排列顺序**——素材 A→B→C 和 C→B→A 是两条不同成片。

> **核心流程：** 素材池上传 → 勾选参与合成（≤6 条）→ 设定规则（段数 / 转场 / 上限）→ 生成一批成片 → 勾选导出到任务中心

```
上传/资源库 ──→ 素材池 ──→ 勾选 ≤6 ──→ 排列引擎 ──→ 成片批次 ──→ 勾选 ──→ 任务中心
              多选/拖拽    + 规则        P(n, k)                   ≤50 条
```

## 2. 入口

工具箱页面中的「批量混剪」卡片，归属视频工具分组。点击后在内容区上方打开混剪工作台，平台侧栏保持可点击——点击侧栏任意导航项 = 隐藏工作台（保留进度）。

**恢复提示：** 隐藏后再次打开，若素材池非空或已有批次，弹出「检测到未完成的操作」对话框：
- **继续操作**（主按钮）— 回到上次离开的状态
- **重新开始** — 清空素材池与所有批次

## 4. 素材池

### 素材去重

素材池对重复素材做自动识别，覆盖两种情况：

1. **同一文件重复上传** — 同名同大小的文件直接拦截，不入池
2. **不同文件名但内容相同** — 入池时提取视频指纹（时长 + 分辨率 + 首尾帧采样），指纹一致判定为重复

检测到重复时，素材池中已有的那条卡片短暂高亮提示，新的一条不入池，底部 toast 提示「已存在相同素材，已自动跳过」。

### 空态

居中上传引导区：图标 + 「上传视频素材」+ 格式提示（MP4/MOV · 池内不限 · 合成勾选最多 6 条）。双按钮：「上传视频」（主按钮）、「从资源库选择」（描边按钮）。整个区域支持拖拽放入文件。

### 有素材时

竖向列表，每条素材卡片包含：

| 元素 | 位置 | 交互 |
|------|------|------|
| 勾选框 | 左上角 | 勾选 = 参与合成，上限 6 条；满 6 后其余卡片置灰不可点 |
| 封面缩略图 | 中部 | 视频首帧截取，加载前图标占位 |
| 序号角标 | 缩略图左下 | 勾选态显示勾选排名（1-6），未勾选显示池内序号 |
| 「片头」标签 | 缩略图内 | 仅开启片头锁定时，排名第 1 的素材上显示 |
| 时长 | 缩略图右下 | mm:ss |
| 拖动手柄 | 缩略图右上 | 拖拽调整排列顺序 |
| 移除按钮 | 缩略图右上 | 从素材池移除 |
| 文件名 | 卡片底部 | 单行截断，hover 显示完整名 |

### 添加素材

列表末尾「+ 添加」格，点击弹出浮动菜单：
- **本地上传** — 文件选择器，支持多选（音频自动归入配乐）
- **从资源库选择** — 弹出资源库弹窗，已在池中的素材置灰

菜单底部计数：「池内 N · 已勾选 M/6」。

### 底部状态栏

固定显示：「池内 N · 已勾选 M/6 · mm:ss」+ 「清空」按钮。

## 5. 参数面板

素材池下方，下拉选择器组：

| 参数 | 选项 | 默认 |
|------|------|------|
| 每条成片段数 | 3 / 4 / 5 段 | 3 段 |
| 转场效果 | 淡入淡出 / 递进 / 向左滑动 / 向右滑动 / 拉远 | 淡入淡出 |
| 限制产出条数 | 10 / 20 / 50 | 20 条 |
| 更多设置 ⚙ | 齿轮按钮，有改动时亮起指示灯 | — |

转场选项带动画示意。产出条数受排列总数截断（排列总数 < 所选上限时以实际为准）。

### 更多设置（浮层）

1. **片头锁定**（开关）— 开启后第一条勾选素材固定在每条成片首位，只让后面的段落参与排列
2. **配乐**（上传/移除）— 上传一个音频文件作为统一配乐，成片结果区底部出现配乐轨道条（按视频片段时长比例分段，蓝色填充表示覆盖范围）
3. **保留原声**（开关）— 仅有配乐时可用。开启 = 原声 + 配乐混音，关闭 = 仅配乐

## 6. 排列引擎

从已勾选的 n 条素材中取 k 个位置做有序排列：

| 模式 | 公式 | 示例 |
|------|------|------|
| 普通 | P(n, k) = n! / (n-k)! | 6 选 3 = 120 条 |
| 片头锁定 | P(n-1, k-1) | 6 选 3 首位锁定 = 20 条 |

> **前置校验：** 已勾选素材数 ≥ 段数才能生成（3 段至少需要 3 条素材），不满足时生成按钮禁用并显示黄色警告。

**批内去重：** 同一批生成结果中保证每条成片的片段排列唯一，排列引擎跳过已出现过的组合。跨批次生成时同样去重——如果用户用相同素材和参数再次点击生成，新一批只产出上一批未覆盖的排列；当所有排列已被覆盖时，生成按钮禁用并提示「当前素材和参数下的排列已全部生成」。

## 7. 生成与结果展示

### 生成过程

1. 点击「生成 N 条成片」，按钮变为旋转 + 「正在生成…」
2. 结果区顶部插入骨架批次「新一批生成中…」
3. 生成完成后骨架替换为正式批次
4. 历史批次自动折叠，新批次展开置顶，页面滚动到结果区顶部

### 批次结构

每次生成追加一批，可多批叠加。批次头：折叠箭头 + 「第 N 批」+ 元信息（N 条 · 转场名称 · 片头锁定标记）+ 批次级全选勾选框。

### 成片行

每行从左到右：

| 元素 | 交互 |
|------|------|
| 勾选框 | 用于导出选择，跨批次总上限 50 条 |
| 序号 | 批内从 1 编号 |
| 封面 | 第一段素材首帧 |
| 拼接片段 | 横排各段缩略图 + 序号，底部分段色条标签。片头锁定段额外标记 |
| 播放图标 | hover 出现，点击进入拼接预览 |
| 时长 | 各段之和，mm:ss |

## 8. 拼接预览

点击成片行进入全屏弹窗预览，双层视频交替播放模拟转场效果。

**弹窗结构：**
- **顶部** — 标题「拼接预览」+ 转场/配乐标签 · 左右翻页（← 上一条 | 1/N | 下一条 →）· 关闭
- **视频区** — 切段时执行所选转场动画（淡入淡出/推动/滑入等）。有配乐时同步播放
- **进度条** — 按各段时长比例标记切段位置（竖线），可点击跳转
- **控制栏** — 播放/暂停 · 上一段/下一段 · 静音 · 计时器 · 当前段号
- **底部片段条** — 各段缩略图 chip，当前段高亮，点击跳转

键盘：← → 切换成片，Esc 关闭。

## 9. 导出到任务中心

### 底部操作栏

- **全选勾选框** — 最多选 50 条，标签显示「已选 M/50」
- **时长筛选** — 成片时长跨多个 5 秒档位时出现，按「全部时长 / 0-5s / 5-10s / …」筛选
- **导出按钮** — 「导出到任务中心 (N)」，无选中时禁用

> **配乐校验：** 有配乐时，配乐时长必须 ≥ 所选最长成片时长，否则导出按钮禁用，配乐轨道条显示红色警告 + 差值。

### 导出对话框

- 任务名称输入框，默认「混剪-MMDD-转场名」（如「混剪-0907-淡入淡出」）
- 底部显示工具标签「批量混剪」+ 条数
- 确认后 loading 动画，完成后清空已选，顶部 toast「N 条视频已提交至任务中心生成」

### 任务中心列表

导出后在任务中心显示为一行，来源标记「批量混剪」，摘要如「批量混剪完成 5 条」或「批量混剪中」。

## 10. 任务详情页

从任务中心点击混剪任务进入详情页，以**封面卡片墙**展示。

### 顶栏

- 返回箭头 + 任务名称 + 状态标签（「全部合成 ✓」或「N/M 已合成」）
- 配乐名称标签（如有）
- 全选/取消全选 + 批量下载按钮（仅对已合成 + 已勾选的条目生效）

### 卡片状态

| 状态 | 表现 |
|------|------|
| **合成成功** | 显示封面图，hover 出现播放按钮，点击弹窗播放 |
| **合成中** | 封面叠半透明遮罩 + 旋转 + 「合成中」 |
| **排队中** | 封面叠更深遮罩 + 「排队中」（仅当同批有其他条目在合成中时出现） |

卡片左上角勾选圆圈（默认全选），底部：「组合 N」+ 状态标签 + 分辨率。

## 11. 关键约束

| 约束 | 值 | 触发位置 |
|------|---|---------|
| 合成勾选上限 | 6 条 | 素材池勾选框 |
| 导出上限 | 50 条 | 底部全选 + 导出按钮 |
| 成片段数 | 3 / 4 / 5 | 参数下拉 |
| 最少素材数 | = 段数 | 生成按钮禁用 + 警告 |
| 配乐时长 | ≥ 最长成片 | 配乐轨道条警告 + 导出禁用 |
| 成片排列唯一 | 同批 + 跨批均不重复 | 排列引擎自动跳过；全部覆盖时生成按钮禁用 |
| 素材去重 | 同文件 / 同指纹自动跳过 | 入池时拦截 + toast 提示 |
| 素材池容量 | 无上限 | — |
| 产出条数 | 10 / 20 / 50 | 受排列总数截断 |

## 12. 交互细节

**拖拽排序：** 素材池卡片支持拖拽。拖动时源卡片半透明，目标卡片高亮，释放交换位置。未发生位移的拖拽回退为点击（切换勾选）。

**键盘：**
- 素材卡片 Enter/Space 切换勾选
- 成片行 Enter/Space 打开预览
- Esc 按层级关闭（资源库弹窗 → 恢复对话框 → 预览弹窗 → 导出对话框 → 关闭整个工作台）

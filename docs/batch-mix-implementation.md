# 批量混剪：实现方案与设计决策

> 2026-08-25 · 经 grill-me 讨论定稿（对照竞品：筷子科技「合成量产」实测）
> 状态：方案已确认，待实现
> 关联：视频生成 `docs/video-gen-ux.md` · 视频裂变 `docs/video-fanout-ux.md`

## 1. 背景与目标

用户上传同一品牌的几条短视频素材，系统按不同顺序把它们拼接成多条完整的广告成片（每条由 3-4 个素材片段构成），支持转场与配乐。目标：素材级量产——6 条素材可产出上百条不同顺序的完整成片。

与现有功能的分工：视频裂变产出"每一小段"素材变体；批量混剪把几小段拼成一条完整广告。

## 2. 方案总览

```
工具箱 → 视频生成工具 → 批量混剪
  Step 1 素材准备：上传素材（上限 6 条）· 拖拽排序 · 读真实时长
  Step 2 模式：开关「首条模式」（开启=拖素材到第一位锁定，其余位置随机）
  Step 3 出片配置：片段数（3/4 段）· 转场（5 选 1 全局）· 配乐（上传 BGM + 原声开关）· 限制产出（不限制/10/20/50）
  ── 底部实时：「可生成视频 N 条」随配置实时算 ──
  Step 4 生成：模拟进度 → 成片卡片网格（封面/组合序列标签/时长）→ 时长筛选 → 点击前端模拟播放
```

demo 为纯交互展示：前端模拟拼接（顺序播素材 + 转场动画 + 配乐），不真实合成，不走任务中心。

## 3. 交互细节

### Step 1 素材准备
- 本地上传（mp4/mov）；素材上限 6 条
- 卡片列表：缩略图 / 时长 / 顺序编号，拖拽排序（决定组合基准池，也用于首条锁定）
- 上传时读每条视频真实时长（file 元数据），供成片时长计算与筛选

### Step 2 模式（开关）
| 模式 | 行为 |
|---|---|
| 关（自由模式，默认） | 全部素材自由排列组合 |
| 开（首条模式） | 拖任意素材到第一位 → 盖「首条锁定」角标 → 固定为所有成片第一段，其余位置从剩余素材随机 |

首条模式开启未锁定时给引导：「拖动一条素材到第一位，它将在所有成片中固定为第一段」。

### Step 3 出片配置
- **片段数**：3 段 / 4 段单选，默认 3 段；素材在单条成片内至多出现一次
- **转场**：5 选 1 全局（所有连接处同一转场），名称下方 hover 播放 1s CSS 动效演示

| 转场 | 视觉 |
|---|---|
| 变 | 淡入淡出（A 渐隐 / B 渐显） |
| 递进 | 推进（B 从下向上覆盖 A） |
| 向左滑动 | B 从右向左滑入覆盖 A |
| 向右滑动 | B 从左向右滑入覆盖 A |
| 拉远 | A 缩放淡出，B 浮现 |

- **配乐**：上传 BGM（mp3/wav）全局应用 + 原声开关（开=原声+配乐混音，关=仅配乐）；未上传配乐时原声开关置灰
- **限制产出**：下拉 不限制/10/20/50，默认 20；实际产出 = min(排列数, 上限)

### Step 4 生成与结果
- 「生成视频组合」→ 模拟进度（1-2s）→ 成片卡片网格
- 卡片：封面（首段素材首帧）/ 序列标签（`素材3 → 素材1 → 素材5`）/ 时长（片段时长之和）
- 时长筛选下拉：按当前组合集合实际时长分布动态生成档位（如 15-25s / 25-35s / 35s+）
- 点击卡片 → 预览播放器：按序列依次播放素材 video，连接处播放转场动画（CSS transition），配乐 audio 同步；进度条=总时长，可暂停/拖动（拖动=切到对应片段）

## 4. 组合算法（配置即算量）

顺序敏感（**排列**，123 与 321 是两条不同成片）；单条成片内素材不重复；排列天然无重复成片。

| 场景 | 公式 | 6 条素材示例 |
|---|---|---|
| 自由 · 3 段 | P(n,3) | 120 |
| 自由 · 4 段 | P(n,4) | 360 |
| 首条 · 3 段 | P(n-1,2) | 20 |
| 首条 · 4 段 | P(n-1,3) | 60 |

- 展示数学上限（"量大"），生成按限制产出截断
- 素材不足提示：3 段模式至少 3 条，4 段模式至少 4 条

## 5. 设计决策记录

| # | 决策 | 理由 | 备选（已否） |
|---|---|---|---|
| D1 | 工具放工具箱「视频生成工具」分组，与视频克隆并列 | 同属视频产出工具线 | 独立 tab / 独立工作流 |
| D2 | 排序 = 排列（顺序敏感），非组合 | 123 与 321 是不同成片，符合"自由排序拼接"心智；天然去重 | 组合（去顺序） |
| D3 | 双模式用开关：自由 / 首条 | 首条=拖第一位锁定，交互最直接；后续接数据检测后系统可自动推荐首条 | tab 切换；系统标"高数据"角标（数据溯源难，否） |
| D4 | 片段数 3/4 段可选，素材单条内至多一次 | 结构可控、组合数可算 | 固定段数 |
| D5 | 转场 5 选 1 全局统一 + hover 动效演示 | 简单转场、所见即所选；差异化点（筷子 Pro 无转场） | 逐连接点转场（复杂度高，范围外） |
| D6 | 配乐=上传 BGM + 原声开关，复刻筷子 | 用户不要 BGM 时可用纯原声 | 仅配乐；仅原声 |
| D7 | 产出控制=限制产出下拉 + 配置即算量（实时可生成数） | 复刻筷子：显示上限、生成按下限，量感与可控兼得 | 生成条数生成后定 |
| D8 | 时长 = 片段时长之和，作为结果属性 + 动态档位筛选 | 素材时长固定，生成前选时长范围=隐式约束片段数，反而不直观 | 生成前选时长范围（35-45s 式） |
| D9 | 素材上限 6 条 | 3 条只有 6 条组合无量感；8 条自由 4 段=1680 列表过长；6 条+限制产出兜底最优 | 4 条 / 8 条 |
| D10 | demo 纯前端模拟（假拼接、不走任务中心） | 交互展示目标，无合成成本 | 真实 FFmpeg 合成（后续演进） |
| D11 | 预览=前端顺序播素材 + CSS 转场 + audio 配乐 | 与 demo 定位一致，可完整演示转场效果 | 仅静态封面 |

## 7. 技术实现（demo）

- 纯前端 JS（主仓现有技术栈，无后端）
- 拖拽排序：SortableJS 或轻量自研
- 素材：URL.createObjectURL + duration 元数据
- 组合引擎：纯函数（素材数组 + 模式 + 片段数 → 排列序列数组），限制产出截断
- 预览：video 顺序播放 + CSS transition 转场 + audio 配乐，原声开关=video.muted

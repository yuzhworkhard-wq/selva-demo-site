# 爆款视频库交互文档

# 爆款视频库：完整交互链路

---

## 1. 功能定位

爆款视频库是一个**投放素材情报库**，按广告消耗金额排名展示各行业、各渠道的高消耗视频素材。

核心价值链：**发现行业爆款 → 查看提示词 → 一键复用到视频生成。**

用户在这里做两件事：
1. **看**——筛选、排序、对比行业里哪些素材在跑量
2. **用**——把看中的素材的提示词灌进视频生成，或把视频本身丢进克隆 / 裂变

---

## 2. 入口

爆款视频库有两个入口，进来后的页面相同，区别在返回目标。

### 2.1 平台侧栏一级菜单

左侧栏点「爆款视频库」→ 打开库的全页。顶栏没有返回箭头，侧栏高亮「爆款视频库」。

### 2.2 视频生成页内的展示区

视频生成的输入页下半部分是一块「爆款视频库」展示区（见第 3 节）。点「查看全部」→ 打开库的全页，顶栏带返回箭头，点返回回到视频生成。

展示区里的卡片 hover 出现「做相似」，点了**不进库页**，直接把该视频的提示词灌进视频生成输入框（见第 7.1 节）。这是一条快捷路径，用户甚至不需要打开全页就能复用。

---

## 3. 视频生成内的展示区

### 3.1 位置与用途

展示区嵌在视频生成输入页的**输入卡正下方**，在用户还没想好写什么的时候用行业爆款启发灵感。

标题文案：「爆款视频库」。
副文案：「近 7 日消耗最高的投放素材；悬停后点「做相似」，用这条的提示词去制作」。

### 3.2 布局

```
┌──────────────────────────────────────────────────────────┐
│  爆款视频库                                 [查看全部 >]  │
│  近 7 日消耗最高的投放素材；悬停后点「做相似」…              │
│                                                          │
│  [TikTok] [Kwai]                                         │  ← 渠道切换
│                                                          │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ ···   │
│  │     │ │     │ │     │ │     │ │     │ │     │       │  ← 最多 14 张
│  │ 封面 │ │ 封面 │ │ 封面 │ │ 封面 │ │ 封面 │ │ 封面 │       │    全铺画面
│  │     │ │     │ │     │ │     │ │     │ │     │       │
│  └─────┘ └─────┘ └─────┘ └─────┘ └─────┘ └─────┘       │
│                                                          │
│                  [查看全部 爆款视频库]                      │
└──────────────────────────────────────────────────────────┘
```

### 3.3 数据规则

- 只展示当前渠道（TikTok 或 Kwai）近 7 天上传的素材
- 按近 7 日消耗降序排列
- 最多展示 14 条

### 3.4 卡片行为

卡片是全铺画面模式——只有封面图，没有文字信息栏。

| 状态 | 表现 |
|------|------|
| 默认 | 封面图 + 右上角收藏书签 |
| hover | 封面隐藏，自动播放视频（静音）；底部浮出「做相似」按钮 |
| 点击「做相似」 | 把该视频的提示词灌进视频生成输入框（见第 7.1 节） |
| 点击收藏书签 | 收藏 / 取消收藏，持久化到本地 |

### 3.5 「查看全部」

标题行右侧和底部各有一个入口，都进入库的全页。当前选中的渠道（TikTok / Kwai）会带过去。

从视频生成进入库全页后，视频生成的输入状态**不会丢失**——库页覆盖在上面，关闭后输入框里还是之前的内容。

### 4.2 搜索

输入产品名称关键词，不区分大小写。有内容时右侧出现清空按钮。

### 4.3 筛选器

**行业 / 来源 / 类型**：胶囊按钮组，单选切换，默认「全部」。

**投放地区**：多选下拉，可同时勾选多个国家/地区。

**消耗范围**：双输入框，填最低/最高金额。支持 `$` 和 `k` 格式（如 `$5k`）。只填一端则另一端不限。填反了自动对调。

**视频尺寸**：下拉单选——全部尺寸 / 9:16 / 1:1 / 16:9。

**视频时长**：下拉单选——全部时长 / <15s / 15–30s / 30–60s / >60s。

**交互规则**：任何筛选条件变化 → 页码自动回到第 1 页。

### 4.4 时间筛选

两种模式：

- **快捷档位**：今天 / 7天 / 30天 / 90天，按钮组单选
- **自定义范围**：起止日期选择器，选了自定义后快捷档位取消高亮

自定义范围优先于快捷档位。起止填反了自动对调。

### 4.5 排序与视图

**排序**（三选一）：

| 排序 | 说明 |
|------|------|
| 按消耗（默认） | 近 7 日消耗从高到低 |
| 最新 | 上传时间从新到旧 |
| 收藏 | 只看已收藏的，再按消耗排 |

收藏为空时提示：「收藏夹还是空的，浏览视频时点右上角书签即可收藏」。

**视图切换**：宫格 ⊞ / 列表 ☰。

### 4.6 宫格卡片

```
┌────────────────────┐
│ TK  MixReels  网赚  │  ← 渠道 + 产品名 + 行业
│ ┌────────────────┐ │
│ │                │ │

│ │  自动播视频     │ │
│ │                │ │

│ 今日 $2.1k         │
│ 7日 $18.5k    🔖   │  ← 消耗数据 + 收藏
│ 上传 07-25         │
└────────────────────┘
```

点击整张卡片 → 右侧滑入详情面板（见第 5 节）。

### 4.7 列表行

```
[缩略图]  MixReels · TikTok · 网赚 · AI    巴西    25s · 9:16    $18.5k    创建 3 天前  [🔖]
```

点击整行 → 同样打开详情面板。

### 4.8 分页

翻页后自动滚到页面顶部。详情面板里的前后切换可以跨页——切到另一页的条目时自动翻页。

### 4.9 空状态

- 筛选无匹配：「没有匹配的素材，换个产品名或把筛选重置为全部」
- 收藏为空：见 4.5

## 5. 视频详情面板

### 5.1 触发

点击宫格卡片或列表行 → 页面右侧滑入详情面板。卡片区收窄到左半，详情占右侧。

### 5.2 布局

│ │                                       │ │

│                                           │
│ [基础信息]  [提示词]                       │

### 5.3 视频播放

- 点击画面区域切换播放 / 暂停
- 未播放时画面居中显示 ▶ 按钮
- 切换到另一条时：暂停、回到开头、tab 回到「基础信息」

### 5.4 基础信息 tab

展示该视频的所有元数据字段：产品名称、投放渠道、行业分类、视频类型、投放地区、消耗、时长、尺寸等。

### 5.5 提示词 tab

**有预设提示词的视频**：
- 展示该视频的提示词全文
- 文本超过 3 行自动折叠，底部有「展开 / 收起」切换
- 右上角复制按钮，复制成功后图标变 ✓，1.6 秒后恢复
- 底部「使用提示词」按钮 → 触发做相似（见第 7.1 节）

**没有预设提示词的视频**：
- 提示词区域显示「暂无数据」
- 「使用提示词」按钮置灰不可点
- 复制按钮同样置灰

哪些视频有预设提示词见第 8 节。

### 5.6 前后切换

- [←] [→] 按钮在当前筛选结果中前后切换
- 键盘 ← → 方向键同效
- 跨页时自动翻到对应页
- Esc 关闭详情面板；详情面板已关闭时再按 Esc 关闭整个库页（仅从视频生成进入时）

### 5.7 底部操作按钮

| 按钮 | 行为 |
|------|------|
| 视频克隆 | 以该视频为基准进入克隆流程（见第 7.2 节） |
| 视频裂变 | 以该视频为基准进入裂变流程（见第 7.3 节） |

从平台侧栏进入时两个按钮都显示。

## 6. 收藏

- 宫格卡片右上角、列表行右侧都有收藏书签图标
- 点击切换收藏 / 取消收藏
- 收藏数据持久化到浏览器本地，页面刷新后还在
- 排序选「收藏」可只看已收藏的素材

## 7. 与视频生成 / 克隆 / 裂变的联动

### 总览

```
                    ┌─────────────────────┐
                    │    爆款视频库全页     │
                    └──┬──────┬──────┬───┘
            做相似 │  克隆 │  裂变 │
         (灌提示词) │ (灌视频)│ (灌视频)│
                    ▼       ▼       ▼
           ┌────────┐ ┌────────┐ ┌──────────┐
           │视频生成 │ │视频克隆│ │ 视频裂变  │
           └────────┘ └────────┘ └──────────┘
                ▲
                │ 做相似（快捷，不经过库全页）
                │
        ┌───────┴──────────┐
        │   展示区卡片       │
        │ （视频生成内嵌）   │
        └──────────────────┘
```

### 7.1 做相似：灌提示词到视频生成

**触发点**（两处）：
1. 视频生成内展示区卡片 hover →「做相似」
2. 库全页详情面板 → 提示词 tab →「使用提示词」

**结果**：
- 视频生成的输入框里出现该视频的提示词文本
- 输入框自动聚焦，用户可以直接修改后提交
- 模型 / 画幅 / 时长 / 条数使用默认值
- 侧栏高亮切到工具箱

**两种场景的细节差异**：

| 场景 | 行为 |
|------|------|
| 从视频生成 → 查看全部 → 库页 → 使用提示词 | 提示词灌入之前已打开的视频生成输入框，回到视频生成 |
| 从侧栏 → 库页 → 使用提示词 | 新开一个视频生成流程，提示词灌入输入框 |

### 7.2 视频克隆：以库里的视频为基准

**触发点**：库全页详情面板底部「视频克隆」按钮

**结果**：
- 进入视频克隆流程的第一步（上传视频）
- 该视频作为基准素材自动填入
- **不灌提示词**（那是「做相似」的事），用户在克隆流程里自己编辑

### 7.3 视频裂变：以库里的视频为基准

**触发点**：库全页详情面板底部「视频裂变」按钮

**结果**：
- 进入视频裂变流程
- 该视频作为基准素材自动填入
- 用户从头配置裂变参数（选维度、写指令等）

裂变的完整交互见 [video-fanout-ux](./video-fanout-ux.md) 文档。

## 8. 预设提示词覆盖规则

库里的视频量很大，不可能每一条都提前写好预设提示词。只有同时满足以下两个条件的视频才有预设提示词：

1. **近 14 天消耗排名前 15%**
2. **日耗峰值 > $300**

不满足条件的视频：
- 详情面板的「提示词」tab 显示「暂无数据」
- 「使用提示词」按钮和复制按钮均置灰
- 展示区卡片 hover 时**不出现**「做相似」按钮（没有提示词可灌）
- 视频克隆、视频裂变入口不受影响，仍可正常使用

这意味着库的主要浏览价值（看行业趋势、看哪些素材在跑量）对所有视频都成立，但「做相似」这条到视频生成的链路只对头部爆款开放。

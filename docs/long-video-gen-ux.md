# 长视频生成 · UX 交互说明

> 来源：产品 grilling 结论（2026-09-07）。交给研发落地时以本文为准；与短视频路径冲突时，以本文「长视频」规则覆盖。

---

## 1. 功能定位

在现有「视频生成」上增加**长视频精致生成**能力。

| | 短视频（现有） | 长视频（本文） |
| --- | --- | --- |
| 目标 | 快速出片、批量裂变测投放 | 结构可控、主体一致的精致单条 |
| 条数 | 1 / 2 / 4 | **固定 1** |
| 生成方式 | 可黑盒直出 | **禁止黑盒**；超限必须轻编排 |
| 差异化 | 未强调处自动变角色/台词 | 不靠并发生成多条；靠改编排 / 单段重跑 |

**核心价值链：**  
短输入 → 结构化扩写（全局设定 + 分镜）→ 轻量确认 → 全局参考图齐备 → 分段并行生成并拼接 → 按需单段重跑。

---

## 2. 触发条件

### 2.1 何时进入长视频路径

用户所选**时长 > 当前模型的「单次直出上限」**时，进入长视频路径。

- 触发阈值 = **该模型单次可直出的最大时长**（不是 UI 里第一个时长选项）。
- 点「生成」后**不直接提交渲染任务**，先进入编排流程（见第 4 节）。

### 2.2 模型与时长能力

| 阶段 | 长视频上限 | 说明 |
| --- | --- | --- |
| 当前已接模型 | 最长约 **60s** | 以各模型实际单次直出/可编排能力为准 |
| 接入原生约 30s 档模型后 | 可扩展至约 **2min** | 交互按可扩展设计，勿写死仅 60s |
| **omni / Grok** | **不提供长视频** | 模型能力不足；UI 不提供超过其单次上限的时长，或超限选项禁用并提示 |

短视频路径（≤ 单次直出上限）保持现状，不受本文影响。

### 2.3 条数

进入长视频路径后：

- **隐藏或禁用**「一次生成 2 / 4 条」
- **固定为 1 条**
- 不提供长视频批量裂变

---

## 3. 入口与流程嵌套

**同一视频生成弹窗**，不新增长视频独立入口。

```
[输入页：文案 / 参考图 / 模型 / 时长 / …]
        │
        │  点「生成」
        ▼
  时长 ≤ 单次直出上限？ ──是──→ 现有短视频提交逻辑
        │
        │ 否（长视频）
        ▼
  强制结构化扩写
        │
        ▼
  编排确认页（友好摘要卡；高级可展开完整 prompt）
        │
        │  用户确认结构
        ▼
  设定图就绪页（实体占位必须全满）
        │
        │  开始生成视频
        ▼
  分段并行渲染 → 拼接成片
        │
        ▼
  任务详情（支持按分镜重跑）
```

---

## 4. 结构化扩写（强制）

长视频路径下，**无论短视频 Magic 开关如何**，点生成后都必须先做结构化扩写，产出：

1. **全局设定 prompt**
2. **分镜序列 prompt**（每镜一段）

不允许 Magic=off 时落到空白编排让用户从零填写。

### 4.1 全局设定应包含的内容（数据层）

参考产品给定的结构模板，至少覆盖：

- 风格与全局：艺术风格、画幅、运镜与打光、成像质感、剪辑与转场、语言与地域、字幕设定、声音基调、总时长等
- **人物设定**：`@角色名` + 身份/稳定外观等
- **场景设定**：`@场景名` + 场景信息
- **关键物品设定**：`@物品名` + 稳定外观（如有）

一致性依赖 **`@` 引用**：分镜中通过 `@实体` 引用，不在每镜重复写死外貌长描述。

### 4.2 分镜应包含的内容（数据层）

每一镜建议字段：

- 镜头序号与时间范围
- 叙事功能
- 画面与动作（景别 / 机位 / 运镜 / 构图；构图中用 `@` 引用实体）
- 对白（说话人 `@`、音色情绪、文本、时间）
- 音效
- 文字与图形（字幕/disclaimer 等）

### 4.3 扩写输入

- 用户第一步的短输入（及已选模型、时长、画幅等）作为扩写条件
- 扩写结果必须识别出所有需要**全局参考图**的实体列表（人物、场景、物品），供设定图步骤使用

---

## 5. 编排确认页（轻量 UI）

### 5.1 默认：友好摘要卡（不要太重）

用户默认看到：

| 区域 | 展示 | 可编辑（MVP） |
| --- | --- | --- |
| 全局 | 人物 / 场景 / 物品卡片（短描述 + 参考图位预告） | 改短描述；完整字段见高级 |
| 分镜 | 时间轴/卡片列表：叙事功能 + 台词 + 一句话画面摘要 | 改摘要级文案；可删/并不做复杂拖拽也可 MVP 只支持改字 |

主 CTA：**确认结构**（或同等文案）→ 进入设定图步骤。

### 5.2 高级：完整 prompt

提供「高级」入口，展开接近模板原文的：

- 全局设定完整文本/字段
- 逐镜完整字段（景别、运镜、对白细节等）

默认路径不强迫用户改这些字段。

### 5.3 明确不做（本页）

- 专业导演台 / 节点画布
- 一次确认直接黑盒渲染（跳过设定图）
- 长视频 2/4 条裂变

---

## 6. 设定图就绪页（硬闸门）

参考图是长视频正确性的前提：**不允许无参考图开渲。**

### 6.1 占位规则

- 扩写识别出的每个需全局参考的实体（**人物、场景、物品**）都展示占位
- **有空位则禁止「开始生成视频」**
- 不允许用户跳过任一已识别实体

### 6.2 填满方式

每个实体支持：

1. **用户上传**
2. **系统自动生成设定图**并填入占位

用户可对自动图：**替换上传**或**重新生成**。

### 6.3 与第一步附图的关系

- 输入页已上传的参考图 → **自动挂到对应实体卡**
- 从经验看，基本都能对上实体；「未分配参考」仅作极端兜底，**不作为主流程 UI**（不必强调拖拽分配池）

### 6.4 步骤关系

```
确认结构 → 设定图就绪（缺则自动生成可出图）→ 全部占位已满 → 「开始生成视频」
```

自动出的图必须在烧视频额度前可被用户看见并处理（对应 grilling 选项 B）。

---

## 7. 渲染与拼接

### 7.1 策略

- 各分镜 **并行** 调用视频模型生成
- 完成后 **拼接** 为一条成片
- **不做**「上一段延长下一段」的顺序续写（MVP 认为过复杂；信息流广告多为硬切，并行更合适）

### 7.2 单段重跑（MVP 要做）

任务详情中：

- 每一分镜可 **单独重新生成**
- 其余分镜保留
- 重跑完成后 **重新拼接** 整条成片

产品预期：这是分段重提 + 再合成，不是完整 NLE 剪辑器。

### 7.3 整条重来

允许基于已保存的全局/分镜（可先回编排修改）再次提交整条长视频任务；与单段重跑并存。

---

## 8. 与现有短视频能力的边界

| 能力 | 短视频 | 长视频 |
| --- | --- | --- |
| Magic 扩写 | auto / on / off 语义保持 | 强制结构化扩写，不沿用 off 空白 |
| 一次多条 | 1 / 2 / 4 | 仅 1 |
| 参考图 | 按模型上限可选 | 全局实体参考图 **全部必填满** |
| 黑盒直出 | 可以 | 不可以 |
| 任务详情 | 现有逻辑 | 增加分镜列表 + 单段重跑 |

---

## 9. 数据与提示词约定（给研发）

建议任务载荷区分：

- `mode: 'long' | 'short'`（或由时长与模型上限推导）
- `globalPrompt` / 结构化全局对象（含 entities: character | scene | prop）
- `shots[]`：每镜 prompt 与时长、叙事功能等
- `entityRefs[]`：实体 id、`@` 名、参考图 URL（用户上传或自动生成）
- `shotResults[]`：每段视频 URL / 状态（供单段重跑与拼接）

UI 摘要卡与「高级」完整字段是同一数据源的两种视图；高级修改写回同一结构。

---

## 10. 非目标（本期不做）

- 长视频一次生成多条变体（2/4）
- 顺序视频延长（上一段续下一段）作为默认管线
- 设定图步骤允许跳过实体
- omni / Grok 的长视频
- 独立「长视频」一级入口（与短视频完全拆开的产品）
- 重型时间线剪辑器

---

## 11. 验收要点（产品）

1. 选超单次直出时长 → 点生成进入编排，而不是直接出片  
2. 编排默认是摘要卡，高级能看到全局 + 分镜完整结构  
3. 未填满全部实体参考图时无法开始视频生成  
4. 可上传；不传则系统补图，补图后用户仍可换/重出  
5. 成片为单条；输入页条数在长路径下为 1  
6. 任务详情可对某一镜重跑并更新成片  
7. omni / Grok 无法进入长视频路径  
8. 主仓验收：改 `apps/video-clone` 后需 `npm run build`，用 `./scripts/serve.sh` 从平台进入验证（子应用 dev server 不作验收面）

---

## 12. 决策记录（grilling 摘要）

1. 长视频定位精致单条，不做快速裂变  
2. 现网约 60s，后续可到约 2min；omni/Grok 除外  
3. 超模型单次直出 → 必须轻编排  
4. 数据：全局设定 + 分镜；`@` 实体  
5. UI：默认摘要卡 + 高级完整字段  
6. 同弹窗多一步，点生成后进入  
7. 强制结构化扩写  
8. 支持按分镜重跑  
9. 条数固定 1  
10. 实体参考图可上传；缺则系统生成；**不可空着进入渲染**  
11. 结构确认后先设定图就绪，再渲视频  
12. 并行出段 + 拼接  
13. 第一步附图自动挂实体；未分配不做主 UI  
14. 识别出的人物/场景/物品占位全部填满才能下一步

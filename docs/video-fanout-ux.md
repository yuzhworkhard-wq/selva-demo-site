# 视频裂变：完整交互链路

> 给研发的产品/UX 说明。描述当前已落地的交互，作为实现对齐基准。  
> 裂变有两条入口：**任务详情里对某一条成片裂变**，以及**工具箱独立功能「视频裂变」**。面板控件同一套，来源不同。  
> 视频生成主流程见 `docs/video-gen-ux.md`。维度词库见 `source/docs/prompt-fanout-dimensions.md`。

---

## 1. 产品定位

裂变是**控制变量**：拿一条已经能打的片子当底，用户说改什么就改什么，没说的逐字沿用。N 条之间的差异才能归因到「换了人物」或「换了场景」。

和视频生成的差别：

| | 视频生成 | 视频裂变 |
|---|---|---|
| 起点 | 一句话 brief | 一条已有成片（或用户上传的一段视频） |
| 差异怎么来 | Magic Prompt 在留白维度上铺开 | 用户点名的那几维（或自动档位） |
| 画幅 / 时长 | 用户自选 | 锁在基准条上，保证可比 |
| 产出 | 新的一批任务 | 同样是新任务，原片原任务不动 |

两条入口共用 `FanoutPanel`。详情里是弹窗；独立工具是上传完成后内嵌在页面里。

---

## 2. 总览

```
路径 A · 任务详情
    视频生成 / 视频裂变任务详情
        → 选中某一条成功成片
        → 点「裂变」
            →（必要时）先分析该条画面 1.6s
            → 裂变面板
            → 提交
                → 原详情零变化，顶部 toast
                → 任务中心多一行新任务

路径 B · 独立工具
    工作台 · 工具箱 → 视频裂变
        → 上传一条基准视频
        → 同一页展开裂变面板（无「视频 N」序号）
        → 提交
            → 关闭工具
            → 任务中心多一行（工具名称：视频裂变）
            → 点开详情：裂变自「你上传的视频」，没有来源任务行
```

两条路径提交后都进同一套任务详情。详情里可以再裂变，形成链条。

## 3. 路径 A：任务详情里的裂变

### 3.1 入口

详情底栏主按钮 **裂变**。作用对象是当前选中的那一条。

| 当前条状态 | 按钮 | tooltip |
|---|---|---|
| 生成中 | 禁用 | 出片后才能裂变 |
| 失败 | 禁用 | 这条没出片，不能当基准 |
| 成功，且该条有独立维度取值 | 可点 | 以视频 N 为底，换个方向再跑几条 |
| 成功，但读不出该条独有取值 | 可点 | 先分析视频 N 的画面，再以它为底裂变 |

「读不出」的两种情况：

1. Magic Prompt = 关，N 条提示词逐字相同且维度数据为空，差异只在成片像素里
2. 历史任务没存过逐条维度取值

这两种也给点。点开后面板先跑一遍画面分析，再谈「其余逐字沿用」。  
用一批共用的取值去假装「以视频 3 为底」，产品上不允许。

成功成片没有「不说方向再跑一遍」的入口。要变，必须走裂变。

### 3.2 弹窗壳

- 全视口遮罩 + 居中面板；平台侧栏同步叠遮罩
- 点遮罩 / Escape / 右上角 × 关闭（资源库开着时 Escape 先关资源库）
- 标题：「裂变」
- 副文案：「以这一条为底，你说改什么就改什么，没说的原样不动」

### 3.3 基准条认领

面板最上方固定一块，避免用户以为是从零重开：

- 左侧：该条成片缩略图（按序号 seek 到可分辨的一帧）
- 文案：「基准 · 视频 2 · {人物} · {场景}」
  - 人物、场景取自该条维度；这两维当初被用户写死、条上没有取值时，只显示「视频 2」
- 右侧：「没说到的部分逐字沿用」
  - 画面分析转圈时这句话不出现，避免和横幅说两遍

### 3.4 画面分析（仅「读不出」时）

横幅两种状态：

**分析中（约 1.6 秒）**

> 这批 N 条提示词相同，正在分析这一条的画面，读出它的人物 / 场景 / 镜头当作基准…

发送按钮转圈禁用。指令框 placeholder：「正在分析画面…」

**分析完成**

> 基准取自**这一条的画面分析**（提示词里读不出各条差异）——下面这些是模型读到的，不对可以改。

用户写死的维度仍以原 brief 为准，画面分析不覆盖。例如用户写了「场景：街边 ATM」，模型看片看出「户外」也改不掉。

同一条片子每次读出来的取值固定（可对账）。第 1 条和第 3 条读出来必须不同。

### 3.5 面板本体

形态对齐视频生成那张输入卡：上素材 chip，中指令，下底栏。

#### 自动档位（默认开，默认「初级」）

底栏左侧一颗 **自动** 开关。

- 开：右侧出现档位选择（初级 / 中级 / 高级）
- 关：回到自定义指令

三档：

| 档位 | 说明 | 实际会动的维度 |
|---|---|---|
| 初级（默认） | 保持主题，仅调整人物、场景或视觉呈现 | 人物设定、背景环境、光线氛围 |
| 中级 | 保留核心信息，重组叙事结构与关键表达 | 主要形式、开场钩子、开场首句、台词风格、语速节奏、情绪基调 |
| 高级 | 保留创作目标，重新构建内容策略与表达方式 | 人物、场景、形式、运镜、钩子、首句、台词风格、节奏、情绪、结尾号召、转场 |

开着自动时：

- 指令框收起且只读
- 加素材入口收起且禁用
- 用户点进指令框或开始打字 → 自动关掉，指令框恢复

界面**不把维度列表摊给用户确认**。「你是说人物设定吗」是系统的活。用户写一句话，后台认成哪几维。

#### 自定义指令

自动关闭后出现多行输入，最多 200 字。

Placeholder：「想怎么变？比如：换成这张脸、场景挪到户外」

Enter 发送，Shift+Enter 换行。

系统按关键词认维度，细的优先于粗的。例如「开场首句」认到「开场首句」，不会被「开场」吃成「钩子」。

常见说法：

- 换个人 / 换张脸 / 男女 / 族裔 → 人物设定
- 场景 / 室内 / 户外 → 背景环境
- 光线 / 打光 → 光线氛围
- 钩子 / 前三秒 → 开场钩子
- 台词 / 话术 → 台词风格
- 结尾 / CTA → 结尾号召

认不出任何维、又没挂素材、又没开自动 → 发送禁用，tooltip：「先说说要变什么」。

只挂一张图、指令为空：允许发送。产品语义是「换成这张脸 / 这个场景」，图本身就是方向。

#### 参考素材

和视频生成同一套：`+` → 本地上传 / 资源库；配额跟当前选的模型走。

裂变时最常见的动作就是「换成这张脸」。没有图，那句话说不清楚。

新挂的素材会**接在原任务那批后面**一起进新提示词，不是替换。

自动档开着时这个入口收起。

#### 右侧生成参数

| 控件 | 行为 |
|---|---|
| 模型 | 可换。与视频生成同一套两栏选择器 |
| 画幅 | **锁定**，锁图标。沿用基准条。改了就跟基准不可比 |
| 时长 | **锁定**。基准条的时长新模型也支持 → 沿用；新模型只有另一档（例如基准 15s、Google omni 只出 10s）→ 落到新模型那一档，并在输入区上方出警告：「Google omni 只出 10s，跟基准条的 15s 对不上，这批时长会变」 |
| 条数 | 1–8，默认 4 |
| 发送 | 圆形上箭头 |

### 3.6 提交

点发送：

1. 弹窗立刻关上
2. 原任务、原详情、当前选中条**全部不动**
3. 顶部 toast：「已按你的方向提交裂变任务（4 条）」
4. 任务中心多一行新任务，名称：`视频生成 · 裂变 4 条`（从视频生成详情裂出）或 `视频裂变 · 4 条`（从视频裂变详情再裂）
5. 约 5 秒后出片，成败规则与视频生成相同（≥3 条第 3 条挂；输入含「测试失败」整批挂）

新任务带上来路，详情「你的输入」最上方能对上号：

- 来源任务 ID + 任务名
- 基准是「视频 N」
- 「只变 人物设定 / 光线氛围」
- 用户原话：「只换个男女角色长相」
- 若跑过画面分析：标签「基准来自画面分析」

### 3.7 在详情里认出「这批是裂出来的」

右栏「你的输入」顶部来源块：

- 基准缩略图，点开放大（带控制条，用来看片比对；和本页点一下播放的预览位不是同一交互）
- 「裂变自 **视频 2** · 只变 人物设定 · 「只换个男女角色长相」」
- 来源任务 ID 可复制
- 基准任务不在当前会话时，缩略图位显示「—」，tooltip：「基准视频不在当前会话中，无法预览」

提示词 tab 多一色图例「本次在变」。脚本标题会写：

> （只变人物设定，其余沿用基准条；你的指令：只换个男女角色长相）

用户写死过的维度，若这次被点名要变（看完成片改主意了），新指令覆盖旧 brief。

## 4. 路径 B：工具箱独立「视频裂变」

### 4.1 入口

工作台 → 工具箱 → 视频生成工具 → **视频裂变**。

平台铺同一 iframe，发 `selva-vfanout-open`。

顶栏标题：「视频裂变」。返回 / 关闭规则与视频生成相同：已上传视频则保留会话。

### 4.2 上传基准视频

复用克隆工具的上传区，文案换成裂变：

- 主标题：「爆款视频，**裂变更多可能**」
- 说明：「上传一条想继续测试的参考视频，保持基准片的核心内容，按你的方向生成多条视频变体」
- 左侧展示图：`fanout-showcase.jpg`（一条视频裂出多种故事）
- 右侧：点击或拖入 MP4 / MOV，500MB 以内
- 上传中约 1.5 秒转圈
- 完成后：视频首帧铺底，「已选择」；点画面可重选；垃圾桶移除

上传完成前，右侧下方是素材建议（9:16、15–60 秒、画面清晰无水印）。  
上传完成后，建议消失，**同一页下方展开裂变面板**。没有「下一步」。

### 4.3 内嵌面板和详情弹窗的差别

同一套 `FanoutPanel`，独立工具是 `inline`：

- 没有「裂变」大标题
- 没有「基准 · 视频 N」那一块（用户刚传的就是基准，序号无从谈起）
- 画幅写死 **9:16**（上传链路没有画幅选择）
- 默认模型 Seedance 2.0，默认自动 / 初级，默认 4 条
- 画面分析：独立工具没有「一批共用提示词」的问题，一般不走 1.6s 分析；基准取值按空 brief + 上传视频来

自动档、自定义指令、加素材、模型、锁定的画幅/时长、条数、发送——与详情弹窗一致。

### 4.4 中途离开

已上传视频后再进工具，弹：

> 检测到已上传的参考视频，是否继续裂变？

**继续操作**回到上传完成 + 面板态。**重新开始**清掉视频。

Escape 在没有「继续操作」弹窗时，等同返回。

### 4.5 提交

- 按钮旁出现「正在提交裂变任务」
- 工具关闭（会话清掉）
- 任务中心多一行：
  - 名称：`视频裂变 · N 条`
  - 工具名称：**视频裂变**
  - 来源：工具箱
  - 摘要口径与视频生成相同，文案里的「视频生成」换成「视频裂变」

### 4.6 点开这条任务的详情

仍是 `VideoGenTaskDetail`，和视频生成详情同一套界面。差别只在来路：

- 「裂变自 **你上传的视频**」
- **没有「来源任务」那一行**（基准不是任务中心里的片子，摆空 ID 比不摆更让人犯嘀咕）
- 「你的输入」往往没有文字（独立工具的 brief 为空），参考图若裂变时挂过则照常展示
- 点基准缩略图放大：副标题写「这条基准是你自己上传的视频，不来自任务中心」

底栏「裂变」可以再裂：以当前这条成片为底，走路径 A。新任务的来源变成「视频 N」+ 本任务 ID。

「重新编辑」回到独立裂变页，带回：已上传的基准视频、上次的指令 / 档位 / 条数 / 模型 / 参考素材。再提交仍是新任务。

## 5. 两条路径对照

| | 详情内裂变 | 独立工具 |
|---|---|---|
| 入口 | 详情主按钮 | 工具箱卡片 |
| 基准 | 某条已出片的变体 | 用户刚上传的一段视频 |
| 面板形态 | 居中弹窗，带「视频 N」认领 | 上传完成后内嵌，无序号 |
| 原 brief | 沿用源任务的 sourceText | 空 |
| 画幅 | 锁源任务画幅 | 锁 9:16 |
| 新任务 toolName | 跟源任务（多为「视频生成」） | 「视频裂变」 |
| 详情来路 | 裂变自视频 N + 来源任务 ID | 裂变自你上传的视频，无任务 ID |
| 提交后当前页 | 留在原详情 | 关掉工具 |
| 再裂变 | 可以 | 进详情后可以 |

## 6. 脚本怎么写出来（产品语义）

后台只做三件事，界面不解释算法：

1. **认方向**：自动档 → 固定那几维；自定义 → 从那句话里抽维；只挂图 → 图作为参考素材进脚本
2. **取基准**：该条自己的维度；读不出就画面分析；独立上传则按空 brief 补一套
3. **写 N 条**：基准取值整组端过来，只把被点名的维换成第 i 条的新值

脚本里用户原话锁死高亮，系统补全斜体，本次在变的那几维第三色。有分镜结构就沿用用户的镜头，只代入变量。

独立工具 brief 为空时，脚本几乎全是系统补全 + 本次在变；参考图以 `@参考图N` chip 织进脚本。

## 7. 会话、失败、宿主协议

失败规则与视频生成相同，见 `docs/video-gen-ux.md` §9.3。

iframe 消息（与生成/克隆共用通道，靠 type 分流）：

| 方向 | type | 含义 |
|---|---|---|
| 父 → 子 | `selva-vfanout-open` | 打开独立裂变 |
| 父 → 子 | `selva-clone-open-task` | 打开任务详情（生成/裂变详情同一组件） |
| 父 → 子 | `selva-clone-seed` | 灌历史任务，含带 `fanoutFrom` 的种子 |
| 子 → 父 | `selva-clone-task` | 上报列表行（toolName 区分生成 / 裂变） |
| 子 → 父 | `selva-clone-close` | 关掉 iframe |
| 子 → 父 | `selva-clone-modal` | 弹窗开合同步侧栏遮罩 |
| 子 → 父 | `selva-clone-nav` | 重新编辑时把侧栏切到工具箱 |

历史种子里 `fanoutFrom` 只声明三件事：从哪条任务的第几条裂的（或 `videoUrl`）、点名变哪几维、要不要先读画面。具体脚本由子应用按与真人操作同一条路径现算，宿主不存第三份副本。

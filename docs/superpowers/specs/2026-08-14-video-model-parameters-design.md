# 视频生成模型参数同步设计

## 目标

依据 `/Users/a./Downloads/视频模型参数.md` 更新视频生成工具的模型目录与能力参数，并将文档中的前端展示名称应用到模型选择器、当前已选值和新任务详情。

## 数据源与兼容策略

模型能力由一个纯 JavaScript 配置模块集中管理。每个模型包含稳定的内部标识、前端展示名称、可选时长、参考素材上限、提示词字数上限、单条额度和说明文案。

任务数据继续保存稳定的内部标识。界面统一通过展示名称函数渲染模型名称，以兼容历史任务、重新编辑和视频裂变流程。历史 `Google omni` 任务显示为 `omni`。

## 代码结构

新增纯配置模块，导出：

- 模型配置与模型族目录
- 默认模型
- `modelCfg` 配置查询
- `modelLabel` 展示名称查询
- 参考素材类型、标签和文件类型识别等共享能力

`VideoGenModal.jsx` 负责交互和渲染，使用配置模块驱动模型菜单、时长选择、字数计数、参考素材入口、生成拦截与额度展示。

`FanoutDialog.jsx` 改为从配置模块读取共享模型能力，保持视频生成与视频裂变使用同一参数源。

`VideoGenTaskDetail.jsx` 使用 `modelLabel` 展示任务模型。任务载荷中的 `model` 字段继续保存内部标识。

## 状态与数据流

模型选择流程：

1. 用户在模型菜单选择内部标识。
2. 界面通过 `modelLabel` 显示前端名称。
3. `modelCfg` 提供时长、素材、字数和额度参数。
4. 模型切换后，当前时长保留在新模型支持范围内；其余情况回落到该模型首个时长。
5. 提交任务时保存内部标识。
6. 任务详情通过同一展示函数渲染名称。

## 校验与错误处理

生成前校验继续集中由模型配置驱动：

- 素材数量超过模型上限时列出需要移除的数量。
- 素材类型上限为 0 时关闭对应入口，并提示移除已添加素材。
- 提示词超过字数上限时保留原文、显示真实字数并暂停提交。
- 固定时长模型显示锁定态。
- 可选模型目录无法识别历史标识时沿用当前默认模型回退逻辑。

# 裂变档位滑杆设计

## 目标

将任务中心详情中的裂变档位由三个独立卡片改为一条三档滑杆。用户可拖动滑块或点击轨道切换档位；悬停档位刻度时显示该档位的正式说明。

## 交互

- 弹窗打开时默认选中“初级”。
- 档位与自定义裂变指令可以叠加：选中档位时仍可输入产品信息或额外方向，系统合并自动维度与用户点名的维度；切换档位会保留输入内容。
- 三档对应数值 `0 / 1 / 2`，通过原生 `input[type=range]` 支持鼠标、触控和键盘操作。
- 点击任意档位刻度会将滑块定位到对应档位。
- 选中档位的简短说明显示在滑杆下方；悬停刻度显示完整解释。
- 提交协议继续传递现有 `preset` 字段，其他裂变参数不变。

## 文案

- 初级：保持主题，仅调整人物、场景或视觉呈现。
- 中级：保留核心信息，重组叙事结构与关键表达。
- 高级：保留创作目标，重新构建内容策略与表达方式。

## 实现边界

- 修改 `apps/video-clone/src/FanoutDialog.jsx` 和 `apps/video-clone/src/styles.css`。
- 不改变 `EmbedApp` 的任务消息协议、`briefParser` 的裂变数据结构或平台壳逻辑。
- 构建产物通过现有 `npm run build` 写入 `site/clone` 并同步到 `source/clone`。

## 验收

- 默认状态为初级，滑块位于第一档。
- 拖动、点击刻度、键盘左右键都能切换档位。
- 选择档位后 textarea 不可编辑；输入文字后档位取消且 textarea 可编辑。
- 三个档位 hover 均有不冗长的解释提示，移动端不造成横向溢出。
- 现有裂变提交和任务详情流程保持可用。
